Privacy Policy

Last updated: 18 November 2026

GTA6 Clipper is a private tool operated by one person to publish clips to that person's own YouTube channels and Instagram accounts. This policy explains what it does with data.

Google and YouTube data

When the operator connects a YouTube channel, the tool receives an OAuth token from Google with permission to upload videos to that channel and to read basic statistics (such as view counts) of videos on it. The tool uses this access only to upload the operator's clips and to read the statistics of those uploads. It does not access any other Google data, does not access other people's accounts, and does not share, sell or transfer Google user data to anyone.

GTA6 Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Instagram data

When the operator connects an Instagram professional account, the tool uses Meta's official API to publish the operator's clips to that account and to read insights for those posts. No other Meta data is collected.

Storage and security

Tokens are stored encrypted at rest on a private server that only the operator can access, and are used only by the tool. Clip videos, captions and view counts are kept on the same server for the operator's own records.

Data about other people

The tool reads public livestream video and public chat activity to find highlight moments. It does not store chat usernames beyond short-lived processing and does not build profiles of viewers.

Revoking access and deletion

The operator can revoke the tool's YouTube access at any time at myaccount.google.com/permissions, and Instagram access in Meta's Business Integrations settings. Revoking access stops all uploads; stored tokens are then deleted from the server.

Changes

Updates to this policy will be posted on this page with a new date.
